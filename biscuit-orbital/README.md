# Biscuit Orbital Command

A **Fabric mod for Minecraft 1.20.1**: the **Biscuit Uplink** (a walkie-talkie to the Biscuit orbital
network) plus **8 original orbital strikes**, each with its own animation, its own custom sound
effects, and its own way of ruining your day.

Everything here is original: the code, the item texture, the icon and all 18 sound effects are
generated by the scripts in `tools/`. Nothing is copied from other mods.

---

## The Biscuit Uplink

| Action | What it does |
|---|---|
| **Right-click** | Fires the selected strike at the block under your crosshair (up to 300 blocks, loaded chunks only) |
| **Sneak + right-click** | Opens the **strike menu**: pick the strike, the **power** (I / II / III) and **caster safety** |
| Hold it in the hotbar | Live HUD in the action bar: selected strike, power, safety, READY / recharging |

The selection is stored on the item itself, so every Uplink remembers its own settings.

Craft it (survival):

```
. . L        L = Lightning Rod
N S N        N = Netherite Ingot
N R N        S = Nether Star      R = Block of Redstone
```

Or: `/biscuit give` (operators), or find it in the creative tab **Biscuit Orbital Command**.

## The 8 strikes

| Code | Name | What happens | Danger | Cooldown |
|---|---|---|---|---|
| BIS-01 | **Biscuit Railgun** | Red lock-on ring + accelerating countdown beeps, a 3.5 s rising whine, then a beam from orbit kills everything in the column and **drills a shaft from the sky down to bedrock** | 5/5 | 25 s |
| BIS-02 | **Crumb Carpet** | Air-raid siren, a runway is painted along **the direction you face**, three bombers fly over it and drop ~57 whistling bombs, each one a crater | 4/5 | 30 s |
| BIS-03 | **Choco-Chip Meteors** | Warning zone, then 6 seconds of burning meteors (some burn **blue**, ~40 % **hunt players/mobs**), finishing with a huge **mother meteor** | 4/5 | 40 s |
| BIS-04 | **Thunder Wafer** | A rotating black thundercloud forms overhead, three spiral arms of **chain lightning** sweep outward (sand fuses to glass), then a 6-bolt **final judgement** | 4/5 | 35 s |
| BIS-05 | **Black Hole Biscuit** | A black hole with accretion disk and jets **drags in every living thing** around it and digs the earth up, then collapses into a **supernova shockwave** | 5/5 | 60 s |
| BIS-06 | **Frostbite Cookie** | Ice comet, a frost wave erupts **ice spikes** and **freezes everything solid**, freezing fog drains them, then it all **shatters** (frozen targets take massive damage) | 4/5 | 35 s |
| BIS-07 | **Toasted Tornado** | A fireball lands and spawns a **fire tornado that hunts the nearest target** for 10 s, lifting, burning and shredding, then it explodes | 4/5 | 40 s |
| BIS-08 | **Mega Biscuit** | Global siren + 5 s countdown, missile from 230 blocks, **white-out flash**, a fireball that erases everything, blast wave, shockwave ring, **mushroom cloud**, 14 s of radioactive **fallout** | 5/5 | 120 s |

**Power** scales radius, damage and counts: I = standard, II = heavy, III = apocalyptic.
All strike damage uses a custom *"Biscuit Orbital Strike"* damage type that **ignores armor,
enchantments and resistance** (totems still work, creative/spectator players are immune).

**Caster safety** (default ON): you are not hurt by your own strikes. Switch it OFF in the menu
for the hardcore version. Safety only protects the caster, everyone else is fair game.

## Build the jar

You need a jar to put in `mods/`. This project is a normal Fabric/Gradle project.

### Option A: GitHub builds it for you (no installs)

1. Create a new repository on GitHub and upload **everything** in this folder
   (including the hidden `.github` folder. If the web uploader skips it, use `git push`
   or create `.github/workflows/build.yml` manually with the same content).
2. Open the **Actions** tab, run **Build Biscuit Orbital jar** (it also runs on every push).
3. Open the finished run, download the artifact **biscuit-orbital-jar**, unzip it:
   `biscuit-orbital-1.0.0.jar` is your mod.

### Option B: build locally

1. Install **JDK 17** and **Gradle 8.8** (or newer 8.x).
2. In this folder run: `gradle build`
3. The jar is `build/libs/biscuit-orbital-1.0.0.jar`.

> If Gradle complains about a version, open <https://fabricmc.net/develop>, choose
> **Minecraft 1.20.1** and copy the versions it shows into `gradle.properties`.

## Install

1. Minecraft **1.20.1** with **Fabric Loader 0.15+**.
2. Put **Fabric API (0.92.x for 1.20.1)** and `biscuit-orbital-1.0.0.jar` into your `mods` folder.
3. On a server, install it on the server **and** on every client (custom item + sounds).

Quick test in a creative/survival world (you must be an operator for commands):

```
/biscuit give
/biscuit strike railgun 1          # fires where you look, no Uplink needed
/biscuit strike nuke 1 ~ ~ ~       # at your feet: run first!
```

Creative-mode players cannot be damaged, so test damage on yourself in survival with
Caster Safety OFF (and a bed set).

## Commands (operators)

| Command | |
|---|---|
| `/biscuit give` | Gives you a Biscuit Uplink |
| `/biscuit list` | Lists the strike ids (`railgun carpet meteor storm singularity cryo inferno nuke`) |
| `/biscuit strike <id> [power 1-3] [x y z]` | Fires a strike (default: where you look) |
| `/biscuit terrain <true\|false>` | Toggle terrain destruction live |

## Config: `config/biscuit_orbital.properties`

| Key | Default | |
|---|---|---|
| `terrainDamage` | `true` | `false` = strikes only hurt entities and make effects, never break blocks |
| `requireOp` | `false` | only operators can fire the Uplink |
| `casterSafeDefault` | `true` | default of the Caster Safety toggle on new Uplinks |
| `damageMultiplier` | `1.0` | multiplies all strike damage |
| `cooldownScale` | `1.0` | multiplies all cooldowns (`0` = none) |
| `blockBudgetMs` / `blockBudgetMaxMs` | `6` / `30` | milliseconds per tick spent breaking blocks (grows with the backlog) |
| `maxActiveStrikes` | `6` | strikes allowed at the same time |
| `targetRange` | `300` | targeting range in blocks |

## Make it yours (branding)

| What | Where |
|---|---|
| Strike names, codes, colors, cooldowns, menu icons | `src/main/java/com/biscuit/orbital/strike/Strikes.java` |
| Titles shown on screen ("ORBITAL RAILGUN", ...) | the `announce(...)` call in each `strike/impl/*Strike.java` |
| Item name / death messages / creative tab | `src/main/resources/assets/biscuit_orbital/lang/en_us.json` |
| Item texture + mod icon | `python3 tools/make_textures.py` (or paint over the PNGs) |
| Sound effects | `python3 tools/make_sounds.py`, or drop your own **mono .ogg** with the same file name into `assets/biscuit_orbital/sounds/` |
| Particle colors | `fx/Fx.java` |
| Mod name, author, license | `src/main/resources/fabric.mod.json` |

## How it works (short)

* All visuals are **server-side particles and vanilla entities**, so there is no client code,
  no shaders and nothing that can crash the game on the client.
* Terrain is destroyed by a **time-budgeted block queue**: even the nuke carves its crater over a
  few seconds without freezing the server. It never touches unloaded chunks or bedrock.
* Every strike runs inside a safety net: if a strike ever throws, it is logged and only that
  strike is cancelled, the server keeps running.
* Strikes can only target **loaded chunks**; nothing is ever force-loaded or generated.

## Troubleshooting

* *Build error `cannot find symbol` / `method does not exist`*: send the full error text, it points
  to the exact line.
* *Right-clicking while aiming at a chest/door opens it instead of firing*: vanilla block
  interaction wins. Aim at the ground next to it, or use `/biscuit strike`.
* *Server lags during the nuke*: lower `blockBudgetMaxMs`, or set `terrainDamage=false`.
